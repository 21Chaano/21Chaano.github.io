ICS 314 is my first dip into UI frameworks. I have dabbled in a bit of HTML once in my object-oriented programming class, but that was just to introduce myself to the language. Now that I have experienced cascading stylesheets and Bootstrap5, I have some mixed feelings about the whole process of writing the code. I like what it can do, but I really do not like doing it.

## Pretty on the Outside

Let me start off with what I like about UI frameworks. Bootstrap5 makes websites look really nice and all pretty. Its library of icons is very useful since you have a bunch of these ready to go all from the same source. From things like common social media logos to different arrows are symbols for utilities like buttons. There is also the premade container and navbar classes that make the various parts of your website look even prettier than basic CSS. All in all, Bootstrap5 is like pretty makeup to paint on your website and I would like to see what React can do.

## Twisted on the Inside

Now for what is not so fun. Using CSS files with my HTML files were not so bad. I give the blame to HTML for not looking very aesthetically pleasing with how it is written. It can be real easy to get lost with what div block you are in or it can luck really cluttered with how whitespace matters a little too much. Bootstrap5 takes that clunky mess and makes it so much worse.

A simple navbar that can take you five minutes to do using basic HTML and CSS turns into 15 minutes trying to figure out how to fit a navbar together when using Bootstrap5. Bootstrap makes the code so much longer and messier and an overall pain to deal with. Seeing how Bootstrap is implemented makes me worry when I see that I need to learn React next.

## Concluding Thoughts

I may have mixed feelings about these UI frameworks, but I do realize its potential when it comes to UI design and the utility they provide. I just do not like how it can be a pain to read and write yet the final results can be so pretty to look at. The code looks like a beginner poet got too creative with their work. I think that it is a good thing I am learning these, even if software development is not my intended career path. I will keep these tools in my back pocket if I ever need or wish to use them.
